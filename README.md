# 함께 가계부 Android 다운로드

[최신 APK 내려받기](https://github.com/heesooedu/banking-downloads/releases/latest/download/together-banking.apk)

기존 Google Apps Script·Google Sheets 가계부에 연결하는 두 사람용 안드로이드 앱입니다. Firebase·Cloud Run·별도 유료 서버는 사용하지 않습니다. 영수증 AI 비용은 기존 제공사 요금에 따릅니다.

## 설치와 연결

1. Releases에서 together-banking.apk를 내려받아 설치합니다.
2. 본인의 GAS 웹앱 /exec 주소와 기기 이름을 입력합니다. APK에는 개인 가계부 주소·인증 정보가 포함되지 않습니다.
3. 최초 관리자는 GAS 편집기에서 prepareBootstrap_를 실행하고 프로젝트 설정 → 스크립트 속성의 BOOTSTRAP_ONCE를 10분 안에 앱에 입력합니다. 추가 기기는 이 항목을 비워둡니다.
4. 추가 기기의 12자리 확인 코드를 기존 기기의 기기 관리에서 대조해 승인합니다.
5. Android 설정에서 알림 접근을 허용하고 수집할 앱을 선택합니다. 실제 알림의 카드·금액·사용처를 확인한 뒤 카드별 출금 계좌를 연결해야 자동 기록을 켤 수 있습니다.

## 개인정보·사용 제한

- 공개 APK를 설치해도 승인 없이는 가계부에 접근할 수 없습니다.
- 기기 키와 대기열은 Android Keystore로 암호화하고 백업에서 제외합니다. 알림 원문은 서버에 전송하지 않습니다.
- 사진은 선택한 AI 제공사로 분석 요청하고 품목 데이터만 저장합니다. 원본 사진은 보관하지 않습니다.
- 분실 기기는 다른 승인 기기에서 해제할 수 있습니다. 전체 기기 분실 시 GAS 편집기의 resetDevices_로 복구합니다.
- 알림 가림·배터리 관리로 수집이 지연/누락될 수 있습니다. 애매한 건 확인 대기에서 처리하고 기록 후에도 수정할 수 있습니다.
- 첫 버전은 실제 카드 문구·기기별 백그라운드 동작을 확인하며 사용해야 합니다. 금융기관의 확정 거래내역 조회 앱이 아닙니다.

서명된 APK와 SHA256SUMS.txt만 배포합니다. 소스·서명 비밀·금융 기록은 이 저장소에 포함하지 않습니다.
